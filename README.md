# Information Security — Scrolling Web Presentation

A 12-section, responsive, scroll-driven web presentation built with HTML, CSS, and vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best results, use a local development server such as VS Code Live Server.

No build step or package installation is required.

## Features
- 12 presentation sections on Information Security
- Scroll-triggered reveal animations for text, cards, and diagrams
- Animated hero shield, orbit rings, and subtle parallax
- Progress bar, slide counter, chapter navigation, and overview grid
- Keyboard navigation: Up/Down and Page Up/Page Down
- Interactive checklist on slide 11
- Responsive desktop and mobile layout
- Reduced-motion preference support

## Notes
- The presentation is newly authored because no original `.pptx` was supplied.
- Google Fonts and the photographic background on slide 5 require internet access. The core presentation and CSS visuals work offline, but fonts will fall back to system fonts and the photo background will not load.
- This is a web presentation, not an editable PowerPoint file.
